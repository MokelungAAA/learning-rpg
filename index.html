totalQuestions number 必填
correctCount number 必填
accuracy number 必填
📝 考试记录 Exam Record

totalScore number 必填
obtainedScore number 必填
accuracy number 必填

{ "activityType": "recitation", "result": "perfect" // perfect=100%, partial=50%, failed=0% }
