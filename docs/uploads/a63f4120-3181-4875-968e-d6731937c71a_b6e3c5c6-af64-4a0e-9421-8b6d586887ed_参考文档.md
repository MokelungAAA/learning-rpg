## 第一章：产品灵魂与核心原则

### 1.1 系统定位

这是一个个人认知的液态镜面——不是教学工具，不是刷题系统，不是AI老师。系统的角色是忠实的记录者、聪明的分析者、克制的提醒者。

用户是高一学生，这意味着：

- 时间跨度是三年，而非高三最后冲刺的几个月
- 学习节奏有弹性，不存在"每天必须学到凌晨"的紧迫感
- 需要长期激励，防止新鲜感过后的系统冷落
- 知识体系在逐步构建，技能树会随时间自然生长
- 允许探索和试错，高一不是容错率极低的最后关头

### 1.2 三大设计隐喻

**隐喻一：液态玻璃（材料感）**

界面由数层悬浮的透明磨砂玻璃构成。光线穿过每一层时发生折射、散射、色散。用户应该感觉自己在透过一块有厚度的、有温度的光学玻璃观察自己的学习轨迹。这不是简单的 backdrop-filter: blur() 能完成的——需要多层叠加、内部光晕、边缘色散的综合运用。

**隐喻二：生物发光（生命力）**

数据有"生命感"。掌握度高的知识点发出温暖光芒，久未复习的知识点逐渐暗淡。整个界面像深海中的发光水母群——每一点光都是一个知识碎片，连线构成认知网络。高一学生面对的是大量未被点亮的知识区域，这些黑暗不应是压力，而是一片待探索的星域。

**隐喻三：认知温度计（信息可视化）**

每个知识点有温度：刚学完是温热的橙金色，随时间流逝逐渐冷却为深蓝。用户可一眼看出哪里需要"加热"——这是艾宾浩斯遗忘曲线的可视化转译。

### 1.3 设计禁忌（绝对不可触犯）

1. 纯白背景 + 纯白卡片——这不是玻璃，是瓷砖
2. 中二命名——"力学巨兽"、"三角函数深渊"、"单词地狱"——统统禁止
3. 低幼插画或卡通吉祥物——用户是高中生，不是儿童
4. 纯表格形式的数据展示——太像考卷，产生压迫感
5. 刺眼的红色警告(#FF0000)——预警用带有灰度的珊瑚色
6. 空洞鼓励——"你真棒"这类话术禁止，反馈必须基于数据
7. 打断性弹窗——任何非用户主动触发的弹窗都要三思

### 1.4 用户核心行为流

```
用户主动发送学习成果
       ↓
系统解析内容 → 计算XP → 更新技能树温度 → 检测等级触发条件
       ↓
用户查看仪表盘 → 发现薄弱点 → 自行调整学习方向
       ↓
用户做高考卷 → 发送成绩 → 系统验证等级 → 自动解锁下一阶段
```

系统不会主动出题、不会推送练习题、不会要求用户做什么。用户自己决定学什么、何时检验。

## 第四章：核心算法与数据逻辑

### 4.1 XP计算引擎

**公式：总XP = 基础完成分 + 勇气挑战分 + 回顾修正分**

- **基础完成分**：有效学习时长(分钟) × 10，单次上限120XP
- **勇气挑战分**：用户当前能力值与题目难度之差 × 30
- **回顾修正分**：附带错因分析或笔记链接 → 固定 +15XP

**衰减机制**

- 同知识点24小时内重复练习，仅获50%基础完成分
- 单日同一科目累计超3小时，超出部分XP效率降为50%

### 4.2 等级与过关系统

#### 双轨等级系统
- **总等级**：全局等级，综合所有学科表现
- **学科等级**：每个学科独立等级，互不影响

| 等级 | 得分率 | 日文称号 | 含义 |
|------|--------|----------|------|
| Lv1 | 初始 | 初学者 | 一切尚未开始 |
| Lv20 | 80%(学考) | 見習い | 刚入门 |
| Lv30 | 90%(学考) | 半人前 | 摸到门道 |
| Lv40 | 40%(高考入门) | 修行者 | 正式踏上高考之路 |
| Lv50 | 50% | 門下生 | 开始系统掌握 |
| Lv60 | 60% | 術士 | 能运用知识解题 |
| Lv70 | 70% | 指南役 | 可辅导他人 |
| Lv80 | 80% | 免許皆伝 | 充分掌握真传 |
| Lv90 | 87% | 達人 | 游刃有余 |
| Lv100 | 92%(封顶) | 極意 | 登峰造极 |

**进阶标准（通用）**：
- 需连续两次达标才算正式升级
- 升级后7天保护期，期间不降级
- 每次验证使用高考卷/模拟卷成绩

**学科等级计算**：
- 根据该学科的学习记录、正确率、XP综合评估
- 不要求每科同时达到同一等级
- 学科等级独立于总等级

### 4.3 新用户数据初始化
- **首次使用**：所有数据从零开始
- 总等级：Lv1
- 学科等级：全部 Lv1
- XP：0
- Combo：0
- 知识点温度：全部冻结(0%)

### 4.3 智能推荐算法

六大排序维度：紧迫度、短板优先、循序渐进、教辅匹配、XP效率、防重复。

### 4.4 遗忘曲线与阴影复习

知识点温度随时间冷却，放入"阴影复习队列"，当用户学习相邻知识点时温和呈现。

## 第八章：数据交互规范

### 8.1 教辅选择式记录（核心输入方式）

用户不应手动输入知识点，而应通过选择教辅+章节的方式记录学习，系统自动识别知识点。

**记录流程：**

### 二、温度模型重构

#### 新节点数据结构
```javascript
{
  peakTemp: 85,      // 复习后峰值
  lastStudy: timestamp,
  halfLifeDays: 4.0, // 动态半衰期
  repetitions: 1,
  accuracyHistory: []
}
```

#### 温度计算（只降不升）
```javascript
function getCurrentTemp(node) {
  const elapsedDays = (now - node.lastStudy) / MS_PER_DAY;
  const retention = Math.pow(2, -elapsedDays / node.halfLifeDays);
  return Math.max(0, +(node.peakTemp * retention).toFixed(1));
}
```

#### 复习升温（温度可升）
```javascript
const boost = Math.min(50, Math.max(10, accuracy * 0.4 + 10));
node.peakTemp = Math.min(100, getCurrentTemp(node) + boost);
node.lastStudy = now;
node.repetitions++;
```

### 四、学科等级算法

#### 三维度评分
- **广度(B)** = min(100, nodeCount / 20 * 100)
- **深度(D)** = avgCurrentTemp
- **经验(E)** = log2(1 + totalXp/1000) / log2(51) * 100

#### 综合分
```
S = (B^0.3) * (D^0.4) * (E^0.3)
```
线性映射到Lv1-100。
