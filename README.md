# 学习RPG · 认知操作系统

> 基于艾宾浩斯遗忘曲线的游戏化学习追踪系统

🔗 **在线访问**: https://mokelungaaa.github.io/learning-rpg/

---

## 项目简介

学习RPG是一个将学习过程游戏化的追踪系统。它把"学习"变成"打怪升级"：

- 你学习一个知识点 → 系统记录 → 知识点有"温度"（记忆强度）
- 温度随时间衰减（遗忘曲线）→ 需要按时复习"加热"
- 复习获得 XP → XP 累积升级 → 解锁称号

## 微信机器人助手写入数据指南（AI指令版）

> 以下是指令，直接告诉微信AI（ClawBot）如何解析我的消息并写入 `data/data.json`。

### 核心规则

**我的消息可能非常简短**，只有几个词甚至一个词。你必须从碎片信息中推理出完整字段。以下是优先级规则：

```
优先级1：消息中明确提到的 → 直接使用
优先级2：消息中暗示的 → 使用默认关联
优先级3：完全没说到的 → 使用默认值
```

### 5个必填字段

| 字段 | 我可能怎么说 | 你该怎么填 |
|------|-------------|-----------|
| `subject` | "数学""物理""化学""英""语""史"等简称 | 映射到九大学科全称（见下方） |
| `textbook` | "必修一""必修第一册""必修1""选必2"等简写 | 标准化为"必修第X册"或"选择性必修第X册" |
| `chapter` | "第三章""第3章""3章""3" | 提取数字，填整数 |
| `score` | "对15题""75分""六成""还不错""没怎么懂" | 映射到 0-100 数值（见下方） |
| `duration` | "半小时""30分钟""两小时""2h""一下午" | 统一转换为分钟数 |

### 九大学科简称映射表

| 我发的 | 你填的 `subject` |
|-------|-----------------|
| 数学、数 | 数学 |
| 语文、语 | 语文 |
| 英语、英 | 英语 |
| 物理、物 | 物理 |
| 化学、化 | 化学 |
| 生物、生 | 生物 |
| 历史、史 | 历史 |
| 地理、地 | 地理 |
| 政治、政 | 政治 |

### Score 推断规则（最关键！）

**我没说分数时，从语气推断：**

| 我说的 | 填 `score` | 含义 |
|-------|-----------|------|
| "全对""都会""很简单" | 95 | 优秀 |
| "还行""大部分会" | 80 | 良好 |
| "一般""差不多" | 65 | 及格 |
| "好难""不太会""没懂" | 40 | 薄弱 |
| "完全不会""崩溃" | 20 | 需加强 |

**我说了具体数字时：**
- "xx题对xx题" → score = 正确数 ÷ 总题数 × 100
- "考了xx分" → 直接使用（满分100时），或 score = 得分 ÷ 满分 × 100
- "掌握了x成" → score = x × 10

### 时长推断规则

| 我说的 | 填 `duration` |
|-------|--------------|
| 没说时长 | 默认 30 |
| 半小时、30分钟、30min | 30 |
| 一小时、1小时、1h、60分钟 | 60 |
| 两小时、2小时、2h | 120 |
| 一下午、整个下午 | 180 |
| 一节课、两节课 | 45、90 |
| 一会儿、没多少 | 20 |

### 教材和章节推断

- 如果是正常学校进度，默认当前在学教材。**不清楚时先反问我**
- 考试记录：`textbook` = "考试"，`chapter` = 0
- 网课：`textbook` = 课程名称（如"黄夫人力学""一数同步"），`chapter` = 当前学到第几章

### id 和时间生成

```json
"id": "rec-" + 当前时间戳后4位
"timestamp": 当前时间的 ISO 8601 格式（带+08:00时区）
```

### 写入的 JSON 格式

**不要修改 `data.json` 的任何已有内容。** 只在 `records` 数组末尾追加一条：

```json
{
  "version": "2.0",
  "lastUpdated": "当前ISO时间",
  "learnerName": "墨澜",
  "records": [
    ...原有记录保持不变...,
    {
      "id": "rec-XXXX",
      "timestamp": "2026-05-16T19:30:00+08:00",
      "subject": "数学",
      "textbook": "必修第一册",
      "chapter": 3,
      "score": 75,
      "duration": 30
    }
  ]
}
```

### 简短消息解析示例

| 我发的 | 你解析的 |
|-------|---------|
| "数学必修一第三章30分钟" | subject=数学, textbook=必修第一册, chapter=3, duration=30 |
| "物理第二章45分钟全对" | subject=物理, textbook=必修第一册, chapter=2, duration=45, score=95 |
| "英语考的还行" | subject=英语, textbook=考试, chapter=0, duration=0, score=80 |
| "化学60分钟一般" | subject=化学, textbook=必修第一册, duration=60, score=65 |
| "今天没学" | 不写入任何记录 |
| "写错了删掉上一条" | 删除 records 数组最后一条 |

### 批量录入

多条记录用逗号或换行分隔，每条单独解析。例如：
> "数学三30分钟80分，物理二45分钟，英语考试75分"
→ 解析为3条独立记录依次追加。
