# 学习RPG · 认知操作系统

> 基于艾宾浩斯遗忘曲线的游戏化学习追踪系统

🔗 **在线访问**: https://mokelungaaa.github.io/learning-rpg/

---

## 项目简介

学习RPG是一个将学习过程游戏化的追踪系统。它把"学习"变成"打怪升级"：

- 你学习一个知识点 → 系统记录 → 知识点有"温度"（记忆强度）
- 温度随时间衰减（遗忘曲线）→ 需要按时复习"加热"
- 复习获得 XP → XP 累积升级 → 解锁称号

## 核心功能

### 1. 教材进度地图
- 每科每本书的章节进度条
- 一眼看出"学到哪了"、"哪章薄弱"

### 2. 知识掌握热力图
- 知识点掌握度矩阵
- 颜色编码：🟢优秀 🟡及格 🟠薄弱 ⚪未学

### 3. 学习日历
- 每日学了什么、时间线
- 简单的日历视图

### 4. 网课进度同步
- B站课程学习进度追踪
- 一数/黄夫人/学过石油/一生儿/一化儿/FREE高考英语

## 数据输入方式

### 精简格式（v2.0）

只需提供4个字段：

```json
{
  "subject": "数学",
  "textbook": "必修第一册",
  "chapter": 3,
  "score": 75,
  "duration": 30
}
```

系统自动计算：知识点列表、温度、XP、等级等。

详细规范见 [docs/DATA_FORMAT_v2.md](docs/DATA_FORMAT_v2.md)
