> 基于艾宾浩斯遗忘曲线的游戏化学习追踪系统

🔗 **在线访问**: https://mokelungaaa.github.io/learning-rpg/

---

## 项目简介

学习RPG是一个将学习过程游戏化的追踪系统。它把"学习"变成"打怪升级"：

- 你学习一个知识点 → 系统记录 → 知识点有"温度"（记忆强度）
- 温度随时间衰减（遗忘曲线）→ 需要按时复习"加热"
- 复习获得 XP → XP 累积升级 → 解锁称号

## 微信机器人助手写入数据指南

### 数据流概览

```
你在微信发消息 → 微信机器人解析 → 写入 data.json → GitHub自动同步 → 网页读取渲染
```

微信机器人是你的**数据写入入口**。你只需在微信上发送自然语言的学习记录，机器人就会自动解析并写入 `data/data.json` 文件，网页端下次刷新即可看到更新。

---

### 核心数据格式（v2.0 精简格式）

每条学习记录只需 **5 个字段**：

```json
{
  "id": "rec-001",
  "timestamp": "2026-05-16T14:30:00+08:00",
  "subject": "数学",
  "textbook": "必修第一册",
  "chapter": 3,
  "score": 75,
  "duration": 30
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | ✅ | 唯一标识，格式 `rec-xxx`，机器人自动生成 |
| `timestamp` | string | ✅ | ISO 8601 时间戳，机器人自动生成 |
| `subject` | string | ✅ | 学科中文名（九大学科之一） |
| `textbook` | string | ✅ | 教材/课程名称 |
| `chapter` | number | ✅ | 章节号 |
| `score` | number | ✅ | 学习效果评分 0-100 |
| `duration` | number | ✅ | 学习时长（分钟） |

### 微信聊天示例

#### 场景 1：刷题记录

> **你发：** 学了数学必修一第三章，30分钟，20题对15题
>
> **机器人解析：**
> - subject = "数学"
> - textbook = "必修第一册"
> - chapter = 3
> - score = 15÷20×100 = 75
> - duration = 30
> - XP = round(75×30÷20) = 113
>
> **写入 data.json：**
> ```json
> {
>   "id": "rec-171016",
>   "timestamp": "2026-05-16T14:30:00+08:00",
>   "subject": "数学",
>   "textbook": "必修第一册",
>   "chapter": 3,
>   "score": 75,
>   "duration": 30
> }
> ```

#### 场景 2：看网课

> **你发：** 看了黄夫人物理力学第2章，40分钟，感觉掌握了六成
>
> **机器人解析：**
> - subject = "物理"
> - textbook = "黄夫人·高一物理·力学"
> - chapter = 2
> - score = 60（六成）
> - duration = 40
>
> **写入 data.json：**
> ```json
> { "id": "rec-171017", "timestamp": "...", "subject": "物理", "textbook": "黄夫人·高一物理·力学", "chapter": 2, "score": 60, "duration": 40 }
> ```

#### 场景 3：考试记录

> **你发：** 英语期中考试，满分100得了75分
>
> **机器人解析：**

> - chapter = 0（考试无章节）
> - score = 75
> - duration = 0（考试不计时长）
>
> **写入 data.json：**
> ```json

> ```

#### 场景 4：复习记录

> **你发：** 复习了化学必修二第五章，25分钟，感觉都还记得

### XP 自动计算公式

```
XP = round(score × duration ÷ 20)

约束：
- 最低 5 XP
- 最高 150 XP
```

---

### 写入的 data.json 完整结构

机器人填入的是 `records` 数组中的记录，网页端自动根据 `textbooks.json` 和 `courses.json` 关联知识点并计算温度、等级等。

```json
{
  "version": "2.0",
  "lastUpdated": "2026-05-16T14:30:00+08:00",
  "learnerName": "墨澜",
  "records": [
    {
      "id": "rec-171016",
      "timestamp": "2026-05-16T14:30:00+08:00",
      "subject": "数学",
      "textbook": "必修第一册",
      "chapter": 3,
      "score": 75,
      "duration": 30
    }
  ]
}
```

> **注意：** `records` 数组按时间顺序存放所有学习记录。机器人每次写入追加到数组末尾。不需要修改 `subjects` 或 `profile` 部分，网页端会自动从 records 重建这些数据。

### 常见问题

**Q: 需要手动编辑 data.json 吗？**
A: 不需要。所有数据通过微信机器人自动写入，你只需在微信上发消息即可。

**Q: 支持批量写入吗？**
A: 支持。一次微信消息中可以包含多条学习记录，机器人会逐条解析并写入。

**Q: 什么时候能刷新网页看到数据？**
A: 写入并推送到 GitHub 后，网页刷新即自动拉取最新数据。延迟通常在 1-3 分钟。

**Q: 写错了怎么办？**
A: 发送"撤回上一条"或手动告知机器人删除指定记录 ID。
